# All Motors

Sistema de gestão e vendas da **All Motors**, loja especializada em bicicletas elétricas, patinetes e acessórios.

## Sobre o projeto

Este repositório reúne toda a base do sistema de CRM da All Motors, usado para acompanhar leads, vendas, estoque, test rides, assistência técnica e pós-venda, tanto pela equipe no computador quanto pelo celular.

## Estrutura do repositório

O projeto está organizado em três partes:

- **Frontend:** interface web e mobile, com painel de vendas, funil de negócios, catálogo de produtos e telas de atendimento ao cliente.
- **Backend:** regras de negócio, autenticação de usuários e integrações com as demais partes do sistema.
- **Infraestrutura de dados:** banco de dados, armazenamento de arquivos (como fotos de produtos) e configurações de implantação.

## Identidade visual

A interface segue a identidade da marca All Motors, com vermelho como cor principal, grafite nos menus e textos e fundo cinza claro nas telas.
