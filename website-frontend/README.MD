# All Motors | Frontend

Interface web e mobile do CRM 360° da All Motors, construída com React,
TypeScript, Vite e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

O frontend ficará disponível em `http://localhost:5173`.

## Verificações

```bash
npm run lint
npm run build
```

## Telas

- Dashboard regional
- Pipeline de vendas
- Test-rides e frota
- Catálogo AIMA
- Omnichannel
- Clientes 360°
- Automações e relatórios
- Login e ações rápidas do CRM

O conteúdo atual usa dados demonstrativos enquanto as integrações com o
backend ainda estão sendo implementadas.
